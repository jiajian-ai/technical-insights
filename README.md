## 阅读方式

1. 下载所需 HTML，或克隆本仓库。
2. 使用 Chrome、Edge 等现代浏览器打开本地 HTML。
3. 正文、配图、公式、目录、折叠与图片放大均可离线使用；访问参考资料的原网站需要联网。

GitHub 文件页用于存储和版本管理。阅读交互报告时，请下载原始 HTML 后在本地浏览器打开。

## 后续归档约定

- 按 `洞察/年份/月份/中文报告标题.html` 保存成品。
- 每新增一份报告，同步更新上方目录；后续修订保留在原报告路径，由 Git 记录版本。

- 默认不提交原始图片、生成脚本、开发依赖、过程截图或验收目录；成品 HTML 内嵌的配图保留。
